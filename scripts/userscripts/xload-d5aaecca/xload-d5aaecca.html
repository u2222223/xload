HTML5视频播放增强

全能视频播放增强：倍速/截图/画中画/全屏

Overview

一款通用的 HTML5 视频播放增强工具，支持倍速调节、视频截图、画中画、网页全屏、快进快退、音量控制等丰富功能。内置快捷键系统，所有按键可自定义。兼容 B站、YouTube、爱奇艺、腾讯视频等主流视频站点，通用能力对所有 H5 视频页面生效。支持倍速记忆、长按加速、配置导入导出。

Key features

  • 倍速调节与记忆
  • 一键视频截图
  • 画中画模式

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

点击页面左下角的悬浮按钮打开功能面板，可调整以下选项：

  • 倍速记忆：按站点（B站 / YouTube / 其他）分别记忆上次播放速度，或关闭记忆保持 1.0x。
  • 快捷键：查看默认按键表，点击"录制"可自定义每个动作的快捷键（支持 Shift/Alt/Ctrl 组合）。
  • 长按加速：开启后按住左/右键可连续快进/快退。
  • 其他开关：网页全屏、画中画、截图命名等。

所有配置保存在浏览器本地（GM 存储），支持一键导出 / 导入配置备份。

// 默认快捷键示例
←/→       快退/快进 5 秒        ↑/↓      音量 ±10%
Space     播放/暂停            F        网页全屏
[ / ]     降低/提高倍速        C        视频截图
I         画中画               M        静音

Privacy & permissions

脚本在视频页面读取 <video> 元素并注入快捷键与播放控制，仅在 HTML5 视频页面运行。截图与缓存功能完全在本地浏览器完成，不收集、不上传任何个人信息；所有配置保存在本地浏览器存储中，无需注册账号。宿主站点（xload.net 等）页面自动跳过。
