抖音互动内容屏蔽

弹幕、评论、礼物特效统一屏蔽，关键词与用户黑名单

Overview

统一管理抖音直播弹幕、评论区、礼物特效的屏蔽规则，支持关键词过滤、用户黑名单，被屏蔽内容可选折叠或完全隐藏，规则跨场景复用。

Key features

  • 直播弹幕关键词/用户屏蔽
  • 评论区用户黑名单与关键词过滤
  • 礼物与进场特效屏蔽

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

在抖音网页版（*.douyin.com / *.iesdouyin.com）页面右下角「xload 工具」悬浮按钮组点击「互动屏蔽」打开独立功能面板，面板分四个标签页：

  • 弹幕屏蔽：直播弹幕关键词/用户屏蔽，可开启「屏蔽全部弹幕」总开关。
  • 评论屏蔽：评论区用户黑名单与关键词过滤，支持「折叠占位条（可点击展开）」或「完全隐藏」两种方式。
  • 礼物特效：礼物动画 / 进场特效 / 点赞播报 / 粉丝牌图标独立开关（CSS 隐藏，可还原）。
  • 规则管理：统一增删关键词/用户规则，可标注适用场景（弹幕 / 评论 / 全部），按「类型:值:场景」格式导入导出。
# 规则示例（规则管理页）
词:广告:弹幕      # 弹幕含「广告」屏蔽
词:开箱:全部      # 弹幕和评论都生效
用户:某昵称:评论  # 屏蔽某用户在评论区的发言
/^刷屏+/:弹幕     # 正则匹配，支持 /正则/ 写法

Privacy & permissions

脚本仅在抖音网页版运行时处理浏览器中已加载渲染的互动内容（DOM 层），不干预服务端数据。所有屏蔽规则与统计保存在浏览器本地存储（localStorage），不向任何第三方发送数据。屏蔽仅作用于当前页面的呈现层，不影响主播数据真实状态。
