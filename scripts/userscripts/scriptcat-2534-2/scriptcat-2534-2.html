抖音播放器增强

画质记忆、禁止自动播放、自定义全屏与背景色

Overview

增强抖音网页版播放器体验，支持画质自动记忆、禁止自动播放、双击/单击全屏可配置、视频区背景自定义、移动端进度条拖拽优化。适合在电脑浏览器上长时间观看抖音视频、希望减少操作步骤的用户。

Key features

  • 画质自动记忆与应用
  • 禁止自动播放开关
  • 双击/单击全屏可配置
  • 视频区背景色自定义
  • 移动端进度条拖拽修复

How to install & use

  1. 安装一个用户脚本管理器，如 Tampermonkey 或 Violentmonkey。
  2. 点击上方 "Download / install" 按钮，在管理器中确认安装。
  3. 打开抖音网页版，点击页面悬浮按钮打开功能面板进行配置。

Configuration

点击页面的悬浮按钮或浏览器扩展菜单即可打开功能面板，可调整以下选项：

  • 画质记忆：记住你选择的清晰度，下次播放自动应用。
  • 自动播放：关闭后视频不会自动开始播放。
  • 全屏触发：选择双击或单击进入全屏。
  • 背景颜色：自定义视频区域背景色。
  • 移动端进度条：修复触屏拖拽进度条不跟手的问题。

Privacy & permissions

脚本仅在抖音网页版（douyin.com / iesdouyin.com）运行，不收集、不上传任何个人信息。所有设置保存在本地浏览器存储中，无需注册账号。
