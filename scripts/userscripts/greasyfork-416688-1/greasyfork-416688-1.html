全局字体渲染增强

无需 MacType，享受细腻网页字体阅读体验

Overview

通过智能 CSS 注入实现全局字体重写，支持中英文分字体设置、抗锯齿平滑、描边阴影、动态缩放等高级渲染效果。内置黑白名单过滤与站点个性化配置，兼容主流浏览器，让网页文字在任何屏幕上都清晰美观。

Key features

  • 全局字体替换，支持中英文分字体设置
  • 抗锯齿+描边+阴影多档渲染效果可调
  • 智能过滤规则，自动豁免 PDF/canvas 等特殊页面

How to install & use

  1. 安装一个用户脚本管理器，如 Tampermonkey 或 Violentmonkey。
  2. 点击上方 "Download / install" 按钮，在管理器中确认安装。
  3. 打开任意网页，点击页面悬浮按钮打开功能面板进行配置。

Configuration

点击页面的悬浮按钮打开功能面板，可调整以下选项：

  • 字体设置：分别指定中文字体与英文字体，或使用系统默认字体。
  • 渲染效果：抗锯齿、描边、阴影、动态缩放的开启与强度。
  • 黑白名单：为指定站点单独配置或完全豁免渲染。
  • 站点个性化：为不同网站保存独立的字体与渲染方案。

Privacy & permissions

脚本在网页中注入本地 CSS 用于字体渲染，不收集、不上传任何个人信息。所有配置保存在本地浏览器存储中，无需注册账号。
