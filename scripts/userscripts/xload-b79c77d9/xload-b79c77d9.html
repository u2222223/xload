通用无限滚动翻页

自动加载下一页，无缝瀑布流浏览

Overview

自动检测页面下一页链接，滚动到底部时无缝加载并追加内容，像瀑布流一样连续浏览。支持论坛、社交、资讯、漫画、小说、搜索引擎等各类网站，内置常用站点规则，可自定义添加新站点。

Key features

  • 滚动到底部自动加载下一页
  • 内置多站点翻页规则
  • 悬浮页码指示器，一键暂停/回到顶部

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

点击页面左下角悬浮页码按钮可暂停/恢复翻页，右键回到顶部。打开功能面板可管理站点规则、调整加载阈值、设置滚动行为等选项。

// 安装脚本后，访问支持的网站即可自动生效
// 左下角悬浮按钮：左键暂停/恢复，右键回到顶部
// 面板中可添加自定义站点规则，填写下一页选择器即可

Privacy & permissions

脚本仅在你访问的网页上运行，读取页面 DOM 中的翻页链接，不收集任何个人数据，不向第三方服务器发送信息，站点规则保存在本地浏览器存储中。
