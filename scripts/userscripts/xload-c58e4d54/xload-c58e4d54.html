GitHub Git Clone Accelerator and SSH Address Copy

Adds accelerated HTTPS and SSH clone addresses to the GitHub clone panel and copies a complete git clone command in one click.

Tags: github · git clone · ssh clone · clone accelerator · clone command

Overview

Cloning from GitHub can be painfully slow or fail completely on unreliable connections. This script adds accelerated HTTPS and SSH clone addresses to the existing clone panel and can copy a complete git clone command with one click. Open the panel to choose HTTPS or SSH, disable clone mirrors that stopped working, or add your own proxy host. The original GitHub address always stays visible, and when clipboard access is blocked the command is shown as selectable text instead. Settings are stored in your browser and the script runs only on GitHub pages.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the panel from the floating button to pick HTTPS or SSH, toggle one-click git clone command copy, reorder or disable clone mirrors, and add a self-hosted proxy host.

1. Open a GitHub repository and expand the Code button. 2. Pick the accelerated HTTPS or SSH address, or copy the full clone command from the panel. 3. Paste it into your terminal and run it.

Privacy & permissions

The script reads the clone panel on GitHub pages and stores your protocol choice, mirror list and copy preference locally. Clone and push authentication still happens in your own Git client, and the script never reads tokens or SSH keys; using a third-party clone mirror means that host can see the repository address you clone.
