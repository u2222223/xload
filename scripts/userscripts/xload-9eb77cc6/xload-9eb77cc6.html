GitHub Single File Quick Download from the File List

Adds a quick download action to every file row of a GitHub repository list so single files can be saved without opening the raw page.

Tags: github · file download · quick download · raw file

Overview

Downloading a single file from a repository normally means opening the file, finding the raw view and saving it. This script adds a quick download action to every file row so you can download file from file list directly. The panel lets you choose direct GitHub download or a configured mirror and enables automatic fallback when a mirror fails. Folder rows are skipped, and rows whose download address cannot be derived are left untouched.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the panel from the floating button to turn the file row action on or off, choose direct or mirror download, and enable automatic fallback to direct when a mirror fails.

1. Open a repository file list on GitHub. 2. Click the quick download action on a file row. 3. If the mirror fails, retry from the panel with direct download.

Privacy & permissions

The script reads the file list on GitHub pages you open and stores your route, fallback and enablement settings locally. The file request goes to GitHub or to the mirror you selected, which can see the file address and your IP address; no account credentials are read or transmitted.
