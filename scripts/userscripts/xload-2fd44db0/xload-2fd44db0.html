123pan Download Limit Unlock

Download large files from 123pan drive and share pages without the size limit.

Tags: 123pan · download unlock · large file download · share page download

Overview

123pan restricts free downloads to smaller files and forces extra steps for larger ones. This script unlocks the 123pan download limit so files over 1 GB can be downloaded from your drive and share pages. It uses the official browser download flow, so the browser's own download manager keeps working. Open a file list, start a download from the userscript panel, and check the real URL or server error in the panel.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the panel from the userscript button to see the files detected on the current page, choose a single file or a batch, and read the latest status and error message for each download.

Open a 123pan drive or share page that lists files, click the userscript button, select a file over 1 GB, start the download and wait for the done event in the panel.

Privacy & permissions

Reads the file list and download URLs from the 123pan pages you open. Download settings are stored locally. Downloads go directly from 123pan servers to your browser; nothing is sent to any other server.
