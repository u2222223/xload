GitHub Download Accelerator for Release, Raw and ZIP Files

Adds mirror download links next to GitHub release assets, raw files and ZIP archives so large files download faster without leaving the repository page.

Tags: github · download accelerator · release download · raw file · zip archive

Overview

Large GitHub downloads often crawl or stall when the connection to the original host is slow. This script adds a release download accelerator entry beside release assets, raw files and ZIP archives while keeping the original GitHub link available. Open the panel from the floating button to reorder mirrors, disable the ones that stopped working, or add your own proxy node. Mirror availability and speed change over time, so a failed download can be retried with another mirror from the panel. The script runs only on GitHub pages and stores your mirror list and settings in your browser.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the panel from the floating button on any GitHub page. Enable or disable each download type (release assets, raw files, ZIP archives), reorder or disable mirrors, and add a self-hosted proxy prefix. Settings are stored locally and reused after script updates.

1. Open a GitHub repository, release page or file page. 2. Find the accelerated entry next to the original download link. 3. If a mirror fails, open the panel, disable that mirror and retry with another one.

Privacy & permissions

The script reads the GitHub pages you open to detect release, raw and ZIP download links, and stores your mirror list, disabled mirrors and link type switches locally in your browser. Download requests are sent to the third-party mirror you select, which can see the repository address and your IP address; no GitHub account credentials or tokens are read or transmitted.
