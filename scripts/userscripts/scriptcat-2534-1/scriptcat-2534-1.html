抖音视频流过滤

自定义过滤抖音视频流中的广告、直播和不感兴趣内容

Overview

支持按关键词、作者、视频类型（广告/直播）等多维度过滤抖音推荐流内容，过滤后自动加载更多保持浏览连续性，规则可导入导出。

Key features

  • 广告与直播一键过滤
  • 自定义关键词/作者规则
  • 过滤后自动续流不卡顿

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

进入抖音网页版，点击页面右下角「xload 工具」悬浮按钮组中的「视频流过滤」打开功能面板，可调整以下选项：

  • 总开关：一键停用/启用全部过滤规则。
  • 预设过滤项：广告视频、直播、图集/图文，可单独开关。
  • 自定义规则：按标题/文案关键词、作者昵称、作者 ID、话题标签（包含/等于/正则）过滤，支持时长区间（毫秒）。
  • 过滤统计：实时展示已过滤/已扫描数量，可清空。
  • 规则导入/导出：JSON 格式，可备份或迁移规则。
# 规则格式示例（面板中编辑，或 JSON 导入）
{ "type": "title", "op": "contains", "value": "广告" }    # 标题含「广告」的视频
{ "type": "author", "op": "equals", "value": "某作者" }    # 指定作者
{ "type": "duration", "op": "lt", "value": 15000 }         # 时长小于 15 秒

Privacy & permissions

脚本仅在抖音网页版（*.douyin.com / *.iesdouyin.com）运行时于页面内做 DOM 内容过滤与滚动，不读取、不篡改登录态，不向任何第三方发送数据。所有过滤规则与统计均保存在浏览器本地存储（localStorage）。过滤行为可能被平台识别为异常浏览，相关风险由使用者自行承担。
