Telegram网页版媒体下载器

一键下载Telegram网页版图片视频语音

Overview

在Telegram网页版（webk/webz）一键下载图片、GIF动图、视频和语音消息。支持从限制下载的私密频道/群组中下载媒体文件，支持批量选择下载，带下载进度提示。

Key features

  • 图片/GIF一键下载
  • 视频下载带进度
  • 语音消息下载

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

安装后打开 Telegram 网页版（建议 webk 版本），点击右下角「xload」悬浮按钮打开功能面板，可调整：并发下载数、命名规则（原始文件名/自动命名）、是否显示页面下载按钮、批量下载类型过滤等选项。

// 在 Telegram 网页版打开任意媒体（查看器 / Story / 语音播放条），点击注入的「下载」按钮即可保存；视频下载时右下角显示分片进度。

Privacy & permissions

脚本仅在 Telegram 网页版（web.telegram.org / webk / webz / weba.telegram.org）运行，在其他页面不生效。下载通过浏览器原生 Range 分片直接拉取 Telegram 媒体服务，不经第三方服务器，不上传下载内容；历史、设置与日志保存在浏览器本地存储。
