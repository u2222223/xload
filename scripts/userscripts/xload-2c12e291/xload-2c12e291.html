YouTube Ad Controls

Manage targeted ad handling on YouTube with an immediate off switch.

Tags: YouTube · Ads · Playback

Overview

Open the floating button to configure page-ad hiding and player-ad handling in a separate panel. Enable each behavior separately and inspect recent actions. Turn handling off and restore elements hidden by the script when needed.

Key features

  • Toggle page-ad hiding and player-ad handling separately
  • Inspect recent actions and unmatched states
  • Disable handling and restore script-hidden elements

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the panel and enable page-ad hiding or player-ad handling; both start disabled. Settings and language are stored per script, with ad switches separated for each supported YouTube host.

Open YouTube or YouTube Music, open the panel, and enable the desired ad control. If normal controls are affected, turn handling off and restore the elements hidden by the script.

Privacy & permissions

The script reads ad-related page and player state on YouTube and stores host-specific switches and language in userscript storage. Recent action counts remain in session memory; diagnostic events and errors are retained in a localStorage ring buffer and can be cleared from the panel. Both are shared with the xload.net panel through messaging. Opening that panel requests its page and assets. The design adds no external ad-classification service; YouTube and xload.net receive normal connection data for their respective requests.
