Pixiv Artist UID, Profile Media, and Work Type Labels

Show and copy Pixiv artist IDs, expose valid profile image links, and label loaded works as single, multi-page, or ugoira

Tags: Pixiv artist · artist UID · work type labels

Overview

Pixiv artist pages do not always keep IDs, profile media, and work types visible together. This script adds Pixiv copy artist ID controls, validated avatar and background links, and Pixiv single multi ugoira labels on loaded work cards. Open the panel on an artist or work page to inspect the detected context and toggle labels. It uses only profile and work information available to the current Pixiv session.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Use the panel to enable UID display, avatar and background links, work type badges, copy feedback, and the preferred interface language.

Open a Pixiv artist or work page, launch the panel, copy the detected UID or profile media link, and enable labels to identify loaded work types.

Privacy & permissions

The script reads artist and work metadata already available from Pixiv and stores display preferences in userscript storage. The xload.net panel receives the detected UID, validated media links, label counts, and command status; no non-Pixiv content service is queried.
