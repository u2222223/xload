Overview

支持知网、万方、维普、皮书、中华医学会、博看期刊等多大学术数据库，在论文详情页一键获取免费下载链接，无需登录付费账号。聚合多站点资源解析通道，智能切换可用接口，提升下载成功率。

Key features

  • 多站点论文解析下载
  • 智能切换可用接口
  • PDF格式直出

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

在论文详情页右下角点击悬浮按钮打开功能面板，可调整以下选项：

  • 默认解析源：选择优先使用的解析源（sci-hub 系列），失败自动切换下一个。
  • 格式偏好：优先 PDF 直链下载，无直链时打开解析源落地页。
  • 每日用量阈值：设置每日下载次数提醒，避免超出免费额度。
  • 下载历史与日志：查看最近 20 条下载记录，可一键重试或清空。

Privacy & permissions

脚本仅在你访问知网、万方、维普、皮书、中华医学会、博看期刊等学术站点时运行，不收集、不上传任何个人信息。所有设置、下载历史与用量统计均保存在浏览器本地存储中，无需注册账号。脚本将论文的 DOI 或标题交给公开解析镜像（sci-hub 系列）获取下载来源，不托管、不分发任何文献内容；涉及绕过平台付费机制的风控风险由使用者自行承担。
