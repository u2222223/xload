Zhihu Dark Reading Helper

Apply a configurable dark reading theme to Zhihu pages and dynamic surfaces.

Tags: Zhihu · dark mode · night reading · theme

Overview

This helper applies a reversible dark reading theme to major Zhihu page surfaces. It supports system-following, light, and dark modes, with optional dimming for bright images and tuned code-block contrast. Use the xload panel to select the appearance, save it, or restore the default Zhihu presentation.

Key features

  • Follow the system or force light or dark mode
  • Style major cards, dialogs, forms, and code blocks
  • Optionally dim bright images

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the xload panel and choose Follow system, Light, or Dark. Adjust image dimming and code-block contrast if needed, then save settings. Restore appearance removes the helper's theme from the current page and resets its preferences.

Open any supported Zhihu page and select Dark in the xload panel for night reading. Choose Follow system to react to operating-system theme changes. Disable image dimming when reviewing photography or design content.

Privacy & permissions

The script reads the browser color-scheme preference and Zhihu page structure to apply local styles. Theme settings are stored in userscript storage. It does not transmit page content; configuration commands and status are exchanged only with the associated xload panel.
