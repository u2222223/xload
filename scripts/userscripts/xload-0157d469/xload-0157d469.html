X Long Post Expander — Read Available Full Text

X long post expander activates supported expansion controls so you can read available long-form text with fewer repeated clicks.

Tags: Twitter · X long post expander

Overview

Repeatedly expanding long posts can interrupt reading on X. The script can automatically expand long posts with supported text controls. Open the panel to enable automatic expansion or apply it to the current page once. It does not unlock unavailable text or bypass account access restrictions.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Automatic expansion starts enabled on supported post views; the panel provides pause and expand-once controls.

Browse an X timeline with long posts, open the panel to check expansion counts and pause or run once if needed.

Privacy & permissions

The script reads post text-expansion controls. Its enabled state, language, and shared launcher position and collapsed state use userscript storage. The panel stores its language and up to 60 diagnostic entries in localStorage; diagnostic entries contain status and errors without full post text. Counts and diagnostics are sent to the XLoad panel without credentials. Native expansion may make ordinary X requests.
