Zhihu Content Filter

Filter Zhihu cards by type, phrases, users, votes, age, and labeled content.

Tags: Zhihu · content filter · keywords · productivity · feed control

Overview

This filter evaluates loaded Zhihu answers, articles, videos, and other labeled cards with rules you control. It supports phrases containing spaces, user rules, vote thresholds, time windows, and switches for Zhihu Direct or Yanxuan content. The xload panel shows editable rules, match reasons, and reversible page statistics without reloading the page.

Key features

  • Filter content types and labeled cards
  • Match phrases containing spaces and user names
  • Combine vote thresholds with time windows

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Use the xload panel to select content types, enter one phrase or user rule per line, set an optional minimum-vote threshold and time window, and toggle Zhihu Direct or Yanxuan filtering. Review a rule before saving, then rescan the active page. Settings are stored in userscript storage.

Enter a multi-word phrase on its own line, enable the desired card types, and save settings. On a Zhihu feed or question page, choose Rescan page to evaluate loaded cards. Open match statistics to see which rule hid each item or pause filtering to restore it.

Privacy & permissions

The script reads text, author labels, visible timestamps, vote counts, and content-type markers from loaded Zhihu page elements. Rules, settings, and local match statistics are stored in userscript storage. It does not report or modify accounts; page summaries are exchanged only with the associated xload panel for configuration and status display.
