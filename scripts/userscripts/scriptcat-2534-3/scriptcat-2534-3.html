抖音界面沉浸优化

沉浸模式+手机模式+自定义主题，专注视频内容

Overview

隐藏顶部导航、侧边栏等冗余元素打造沉浸浏览，支持手机模式模拟移动端布局，视频区/评论区/侧边栏背景色自由定制，支持暗色亮色主题切换。

Key features

  • 多档沉浸模式可选
  • 手机模式宽度可调
  • 分区背景色自定义

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

在抖音网页版（*.douyin.com / *.iesdouyin.com）页面右侧的「xload 工具」悬浮按钮组点击「沉浸优化」打开功能面板，可调整以下选项：

  • 沉浸模式：极简沉浸 / 半沉浸 / 自定义，一键隐藏顶部导航、左侧栏、右侧热榜等冗余元素。
  • 手机模式：模拟移动端布局，宽度 320–600px 可调并居中显示。
  • 主题：暗色 / 亮色 / 跟随系统，支持视频区 / 评论区 / 侧边栏分区背景色自定义（含透明度）。
  • 视频标签自动隐藏：鼠标移入显示、移出延迟隐藏。
  • 元素显隐控制：顶部导航 / 左侧栏 / 右侧栏热榜 / 搜索悬浮栏 / 悬浮提示 / 底部推荐独立开关。
  • 解禁双指缩放：移除页面 user-scalable=no 限制。
# 面板操作要点
- 打开面板后所有开关/滑块/颜色即时下发原页面并持久化（localStorage）
- 面板提供「刷新状态 / 查看日志（一键复制）/ 重置默认」
- 面板地址：https://xload.net/scripts/userscripts/scriptcat-2534-3/panel.html

Privacy & permissions

脚本仅在抖音网页版运行，通过注入 CSS 与属性切换实现界面样式修改，不触碰登录态、不请求平台接口、不读取任何内容数据。所有设置保存在浏览器本地存储（localStorage），不向任何第三方发送数据。脚本使用 @grant none，在页面上下文运行，无需特殊权限。
