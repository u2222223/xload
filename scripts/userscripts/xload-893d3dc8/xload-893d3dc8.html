GitHub Folder Download as ZIP for Any Subdirectory

Packages the current GitHub subdirectory into a ZIP archive in the browser so a single folder can be downloaded without cloning the whole repository.

Tags: github · folder download · subdirectory · zip archive

Overview

Getting a single folder out of a GitHub repository usually means cloning everything or downloading the full archive. This script packages the current directory and its contents into a ZIP file directly in the browser, so you can download subdirectory content without cloning the whole repository. Open the panel to set the archive name template, size and file count limits, and the file source (direct or mirror). If some files fail, the panel lists them and lets you retry only those files. Very large directories are rejected with a clear message instead of producing a partial archive.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the panel from the floating button on a repository directory page to set the archive name template, the maximum archive size and file count, and whether files come from GitHub directly or through a configured mirror.

1. Open a repository subdirectory on GitHub. 2. Open the panel, adjust the name template or limits if needed, and start the archive. 3. Watch progress in the panel and save the ZIP when the done event arrives.

Privacy & permissions

The script reads the directory listing of the GitHub page you open and requests each file to build the archive locally; the archive name template, limits and source choice are stored in your browser. File requests go to GitHub or to the mirror you select, which can see the file addresses and your IP address, and no GitHub credentials are read or transmitted.
