微软积分商城自动签到

自动完成微软积分每日任务

Overview

自动完成 Microsoft Rewards 每日任务获取积分奖励，支持 PC 搜索、移动端搜索、每日活动、阅读文章等任务类型。后台定时运行，进度可视化，积分明细一目了然。

Key features

  • 自动完成PC端与移动端搜索任务
  • 每日活动与阅读任务自动领取
  • 积分进度实时可视化

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

安装后在任意页面点击右下角悬浮按钮打开功能面板，可调整以下选项：

  • 任务开关：单独启用/停用签入、阅读、活动、PC 搜索、移动搜索。
  • 搜索次数：PC 端与移动端每日搜索目标次数（默认 30 / 20）。
  • 风控等级：宽松 / 标准 / 严格，对应不同的搜索间隔与随机抖动幅度。
  • 搜索间隔：自定义最小 / 最大延迟（毫秒），模拟真实搜索节奏。
  • 通知开关：任务完成与出错时是否发送浏览器通知。
  • 每日自动执行：开启后当天首次打开页面时随机延迟自动运行一轮（需保持页面打开）。
  • 授权码：手动粘贴 Microsoft Rewards 授权链接或授权码（3 分钟内有效），用于补充或更新 OAuth 凭证。
# 授权流程（二选一）
# 1. 已在 rewards.bing.com 登录 → 面板点「授权」，脚本用浏览器 cookie 自动完成 OAuth 授权
# 2. 无法自动授权 → 访问 https://login.live.com/oauth20_authorize.srf?...（面板内生成链接）
#    授权后在跳转页复制链接，粘贴到面板「授权码」框提交

Privacy & permissions

脚本在你访问任意页面时以后台方式运行，仅在你主动触发或开启自动执行后，通过 Microsoft Rewards 官方接口（login.live.com / rewards.bing.com / rewardsplatform.microsoft.com / bing.com）完成签到、阅读、活动与搜索任务。脚本不收集、不上传任何个人信息；OAuth 凭证、任务进度与历史记录均保存在浏览器本地存储（GM_getValue/GM_setValue），不会发送给第三方。搜索由脚本在你本机发起，不经过第三方中转服务器。
