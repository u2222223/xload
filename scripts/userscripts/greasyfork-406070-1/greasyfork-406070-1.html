通用小说下载器

一键下载全网小说，支持百站解析

Overview

一款可扩展的通用型小说下载器，支持起点、晋江、笔趣阁等上百家小说站点。在小说目录页一键下载，自动生成 TXT 与 EPUB 文件，支持章节筛选、自定义保存格式、并发下载等高级功能。

Key features

  • 支持百余家小说站点一键下载
  • 自动生成 TXT 与 EPUB 双格式
  • 章节筛选与自定义保存参数

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

All options are configured graphically in the script's floating panel (open it from the ≡ xload button) and are stored locally in your browser. You can toggle:

  • Output formats — TXT, EPUB and HTML(ZIP) for the finished novel.
  • Chapter range & filter — download only chapters 1–100, specific indexes (1,3,5), or skip chapters whose titles match a keyword.
  • Download speed — concurrency (1–10 threads), base/max interval between requests, and automatic retry on failed chapters.
  • File layout — chapter title template ({index} {title}), TXT paragraph indent and EPUB author metadata.
  • Site tokens — optional login cookies/tokens for sites that require them (stored per-site, only used to fetch the current page's content).
  • Excluded sites — hostnames where the script stays inactive.
// Example: download only chapters 1–50 of the current book as TXT + EPUB,
// using 4 parallel requests with automatic retry.
Chapter range : 1-50
Output formats: TXT ✓, EPUB ✓, HTML(ZIP) ✗
Concurrency  : 4
Auto retry   : on

Privacy & permissions

When you open a novel's table-of-contents page and start a download, the script fetches the directory and chapter pages in your own browser to extract the text; it does not upload any content to any server. All settings and download history live in your browser's localStorage and never leave your device. The script matches all sites but stays completely inert on excluded hosts (including xload.net) and only acts on pages you explicitly ask it to process.
