通用小说下载器

一键下载全网小说，支持百站解析

Overview

一款可扩展的通用型小说下载器，支持起点、晋江、笔趣阁等上百家小说站点。在小说目录页一键下载，自动生成 TXT 与 EPUB 文件，支持章节筛选、自定义保存格式、并发下载等高级功能。

Key features

  • 支持百余家小说站点一键下载
  • 自动生成 TXT 与 EPUB 双格式
  • 章节筛选与自定义保存参数

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button above and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

Open the xload panel from the floating button to choose TXT, EPUB or HTML ZIP output, set a chapter range or title keyword, customize chapter names, and adjust concurrency, request intervals and retry behavior.

Chapter range: 1-100 or 1,3,5
Chapter title: {index} {title}
Concurrency: 1-10

Privacy & permissions

The script reads the novel page and same-origin chapter pages to build files locally in your browser. Settings, task history and optional site tokens are stored in browser storage. No reading content, account data or generated ebook is sent to xload.
