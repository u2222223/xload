YouTube CPU Tamer – Reduce CPU Usage and Battery Drain

Reduces YouTube's CPU usage and battery drain on watch, home, embedded, and Music pages by aligning timers with the browser's rendering cycle.

Tags: youtube · cpu usage · performance · battery saver · userscript

Overview

YouTube pages keep running background timers that waste CPU and battery even when nothing is visible, so long sessions can spin fans and drain laptops. This script reduces YouTube CPU usage by rescheduling setTimeout and setInterval calls to align with the browser’s rendering frame, cutting unnecessary task execution. Install it as a userscript for Tampermonkey, Violentmonkey, or FireMonkey, then just open YouTube; no settings are needed. It works on watch, home, embedded, and YouTube Music pages in browsers that support Graphics Acceleration, while prioritizing video-related work to keep playback stable.

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey for your browser.
  2. Click the "Download / install" button and confirm in the manager.
  3. Open the target site and use the script as documented below.

Configuration

No configuration is required: the timer optimization activates automatically on matching YouTube pages when the browser supports Graphics Acceleration. The panel shows the current page scope and throttle state, and lets you turn the module on or off or adjust throttle strength (low, medium, high). All settings are stored locally by the userscript manager.

1. Install the script with Tampermonkey, Violentmonkey, or FireMonkey on a desktop browser that has Graphics Acceleration enabled. 2. Open any YouTube page, such as a watch page, home, embedded video, or YouTube Music. 3. Open the panel from the floating button to confirm the timer optimization is active. 4. Adjust throttle strength or disable the module from the panel if you notice any page issue.

Privacy & permissions

The script runs entirely inside YouTube pages and does not read or transmit personal data. It only observes page timers and rendering activity needed for scheduling, so nothing leaves the browser. It does not access account information, and the panel and settings are stored only in the local userscript manager. The only external network activity is the update check performed by your userscript manager itself.
