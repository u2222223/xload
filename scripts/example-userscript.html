Example Userscript

A reference entry showing how a script is listed before real content is added.

Overview

This page is included for demonstration only. It shows how a fully-structured userscript page should look when you fill in the template. The matching entry lives in scripts-data.json so this tool also appears in the homepage, listing grid and search index.

Key features

  • Automatic listing and search via scripts-data.json
  • Shared header, footer and cookie banner via main.js
  • Built-in ad slots and SEO meta tags

How to install & use

  1. Install a userscript manager such as Tampermonkey or Violentmonkey.
  2. Open the "Install / download" button in the sidebar.
  3. Confirm the dialog in your manager and it will be installed.
